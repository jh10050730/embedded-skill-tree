# 임베디드 스킬 트리

C 언어에서 출발해 전기전자, 컴퓨터 구조, 하드웨어 시스템, 임베디드 시스템, 임베디드 리눅스·소프트웨어까지 이어지는 혼자 공부용 지도입니다.

- 주제 90개, 확인 문제 450개
- 원 하나가 주제 하나이고, 선은 먼저 공부하면 좋은 주제를 잇습니다.
- 원을 누르면 개념 설명과 추천 자료, 확인 문제 5개가 나옵니다. 5문제를 모두 맞히면 완료입니다.
- ‘학습 시작’을 누르면 ‘진행 중’으로 표시됩니다. 문제를 채점해도 자동으로 학습 시작이 기록됩니다.
- 주제를 열면 설명 옆에 그 주제 전용 **AI 채팅창**이 열립니다 (좁은 화면에서는 패널의 ‘AI 채팅’ 버튼).
  - 대화는 주제마다 따로 남고, 다른 주제로 넘어가면 그 대화를 ‘공부 노트’로 정리해 설명 맨 위에 보여 줍니다.
  - 개념 설명마다 있는 ‘질문’ 버튼을 누르면 그 개념에 대한 질문이 입력칸에 채워집니다.
  - Anthropic API 키가 필요합니다 ([platform.claude.com](https://platform.claude.com/settings/keys)에서 발급, 쓴 만큼 요금, claude.ai 구독과 별도). 키는 브라우저에만 저장되고 백업 파일에는 들어가지 않습니다.
  - 기본 모델은 Claude Opus 5.5 이고, ‘AI 설정’에서 Sonnet 5.5 / Haiku 5.5 로 바꿀 수 있습니다.
- 기본은 밝은 화면이고, 오른쪽 위 버튼으로 어두운 밤하늘 화면으로 바꿀 수 있습니다.
- 진행 상황과 AI 대화·공부 노트는 브라우저에 저장되고, `?` 버튼에서 파일로 저장하거나 불러올 수 있습니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다. 설치할 것은 없습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 동작 |
| `data.js` | 분야, 주제 묶음(색), 데이터 형식 설명 |
| `data/*.js` | 분야별 주제 내용 (설명, 추천 자료, 확인 문제, 공부 시간) |

주제를 고치거나 추가하려면 `data/` 폴더의 파일만 수정하면 됩니다. 형식은 `data.js` 맨 위에 적혀 있습니다.
