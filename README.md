# 임베디드 스킬 트리

C 언어에서 출발해 전기전자, 컴퓨터 구조, 하드웨어 시스템, 임베디드 시스템, 임베디드 리눅스·소프트웨어까지 이어지는 혼자 공부용 지도입니다.

- 주제 90개, 확인 문제 450개
- 원 하나가 주제 하나이고, 선은 먼저 공부하면 좋은 주제를 잇습니다.
- 원을 누르면 개념 설명과 추천 자료, 확인 문제 5개가 나옵니다. 5문제를 모두 맞히면 완료입니다.
- 진행 상황은 브라우저에 저장되고, `?` 버튼에서 파일로 저장하거나 불러올 수 있습니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다. 설치할 것은 없습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 동작 |
| `data.js` | 분야, 주제 묶음(색), 데이터 형식 설명 |
| `data/*.js` | 분야별 주제 내용 (설명, 추천 자료, 확인 문제, 공부 시간) |

주제를 고치거나 추가하려면 `data/` 폴더의 파일만 수정하면 됩니다. 형식은 `data.js` 맨 위에 적혀 있습니다.
