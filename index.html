      EMBEDDED · SELF-STUDY

      임베디드 스킬 트리

      전기전자, 컴퓨터 구조, 하드웨어 시스템, 임베디드 시스템, 임베디드 리눅스·소프트웨어 5개 분야를 기초부터 심화까지 이어 놓은 공부 지도입니다. 원 하나가 주제 하나이고, 선은 먼저 공부하면 좋은 주제를 잇습니다.

      1. 가운데 START 에서 출발점선 원 안쪽이 기초, 바깥쪽이 심화입니다. 각 분야의 첫 원은 바로 시작할 수 있습니다.
      2. 원을 눌러 내용 보기‘학습 시작’을 누르면 ‘진행 중’으로 표시됩니다. 개념마다 설명이 있고, 추천 자료와 확인 문제 5개가 이어집니다.
      3. 확인 문제 5개를 모두 맞히면 완료틀린 문제는 해설을 보고 다시 풀 수 있습니다. 완료한 주제와 이어진 다음 주제가 밝아집니다. 진행 상황은 이 브라우저에 자동 저장됩니다.
      4. 모르는 건 옆의 AI 채팅창에 물어보기주제를 열면 설명 옆에 그 주제 전용 AI 채팅창이 열립니다. 다른 주제는 대화가 따로 남고, 다른 주제로 넘어가면 대화를 ‘공부 노트’로 정리해 설명 맨 위에 남깁니다. claude.ai 에서 열면 API 키 없이 내 Claude 계정으로 답합니다.

      선은 권장 순서일 뿐 잠금이 아닙니다. 어떤 원이든 바로 열어 볼 수 있습니다.

      진행 상황 백업

      진행 상황과 AI 대화·공부 노트는 이 브라우저에만 저장됩니다. claude.ai 판은 처음 클릭할 때 GitHub 판과 저절로 맞춰집니다 (작은 창이 잠깐 떴다 닫힘). 파일로 저장해 두면 다른 브라우저나 컴퓨터에서 불러올 수 있습니다. 불러오면 지금 기록과 합쳐지고, 둘 중 한쪽에서라도 맞힌 문제는 맞힌 것으로 남습니다.
